# 開発と検証

通常起動はREADMEを参照。ローカルの実設定はGit対象外で、wrangler.local.example.jsoncから作成します。既存ファイルとデータを上書きしないでください。

- npm test：純粋な配置・解析処理、API認証境界、キャッシュ、学習処理の回帰テスト。
- npm run build：モデル準備、型チェック、Vite本番ビルド。
- npm run test:smoke：本番ビルドをローカルWorkerで配信し、Chromeで実認証・実OCR・キャッシュを検証。AIなしでは翻訳の失敗表示を確認。
- npm run test:smoke -- --ai：同じ検証を実Workers AIで行い、翻訳・履歴も確認。Cloudflareの利用枠を消費します。

スモークテストにはインストール済みChromeとビルド済みdist/clientが必要です。テスト専用のDBを使い、本番と通常のローカルDBは変更しません。画像・認証用パスワードをテスト時に生成し、パスワードをログやソースへ残しません。生成画像、画面、計測結果はGit対象外の.local-workへ保存します。

本番ビルドでService Workerが登録された状態を検証します。Vite開発サーバーだけの確認では、モデルキャッシュが本番でも動くとは判断できません。初回準備、再読込、再撮影、ログアウト、未認証API拒否を確認してください。

スマホ実機ではHTTPSのURLからカメラ権限、キーボード、画面回転、保存領域、初回／再訪時の所要時間を別途確認します。PCの狭い画面での検証を実機測定と扱わないでください。

実モデルはpublic/models/へ自動取得します。モデルの内容を変える場合はsrc/shared/ocr-manifest.tsを生成するスクリプトとキャッシュバージョンを整合させます。固定URLとCacheFirstのまま中身だけ差し替えないでください。
