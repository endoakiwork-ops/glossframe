# 公開範囲

公開するのはアプリのコード、マイグレーション、設定例、自作のテスト、必要なライセンスです。

公開しないもの：

- 個人のテスト画像、漫画・ゲーム・書籍などの素材
- 上記から抽出したOCR文、翻訳、座標付き記録、スクリーンショット
- 私用の実装メモ、古い検証資料、モック画面
- 作者個人の本番Wrangler設定、Cloudflareアカウント／リソースID、認証トークン
- パスワード、ハッシュ、セッション、Cookie、DB、ブラウザ状態
- ローカルパス、個人のGit authorメールアドレス

.private/、.local-work/、.wrangler/、実際の設定ファイルはGit対象外です。Gitの強制追加を使わないでください。権利不明の画像や抽出文は、名前だけ変えて公開テストへ移さないでください。

公開テストの文章・画像・座標は独立に作成したものです。スモークテストは文字をCanvasに描画して画像を作るため、外部のテスト用素材を必要としません。

## 確認

```sh
npm run check:public
npm test
npm run build
```

check:publicはパス、明らかな秘密形式、個人環境のパス、リソースIDの混入を確認します。万能な秘密／著作権判定ではありません。公開前にはステージ内容とGit履歴もGitleaks等で検査し、値を表示しない設定で実施してください。

ローカルでもコミット前の検査を有効にするには、git config core.hooksPath .githooks を実行します。GitHub Actionsでも公開対象チェック・テスト・ビルドを実行します。

公開用のGit author／committerには個人メールを使わない運用とします。新規履歴を作る場合も、既存の第三者ライセンスの著作者表記は除去しません。

.gitignoreは既にコミットした情報を消しません。過去に秘密が出た場合は失効・再発行し、履歴を清掃します。履歴を置き換えても、他人のclone／forkやGitHubのキャッシュまでは消せません。必要に応じてGitHub Supportへ相談してください。

GitHub上ではリポジトリ所有者やpushしたアカウントはサービスの仕様として表示されます。ソースとコミットメタデータを匿名化しても、所有者アカウント自体を隠す機能ではありません。

## 公式デプロイの配布設定

公開する `wrangler.toml` はゼロ埋めの配布用IDだけを含みます。作者の実環境は従来どおりGit対象外の `wrangler.jsonc` に置き、上書きしません。WranglerはJSON/JSONCをTOMLより優先するため、既存PC環境はそのまま利用できます。

公式デプロイは利用者のコピー内の設定へ、その利用者のD1/KV IDを書き込みます。ID単体は認証情報ではありません。`check:public` は作者リポジトリ（GitHub ActionsではGITHUB_REPOSITORY、それ以外ではoriginで判定）の配布設定への実ID混入を拒否し、利用者の別リポジトリでは自動生成IDを許容します。秘密情報・個人設定ファイルの禁止はコピーでも維持します。Secretは `vars` やコミットへ書かず、CloudflareのSecret管理へ入力します。

`INITIAL_OWNER_PASSWORD` の設定例は空です。実パスワード、復旧キー、分析トークンを例に埋め込まないでください。Secret設定画面のスクショを公開しないでください。
